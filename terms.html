The service

The ToonMotion applications are internal publishing tools. They are used only by their operator to upload the operator's own animated manga recap videos to the operator's own YouTube channels, TikTok profile, Instagram account and Facebook Page. Use of platform APIs

The applications use the YouTube Data API, the TikTok Content Posting API and the Meta Graph API only for the operator's own accounts, within each platform's developer terms and community guidelines. Every video is posted with the caption and privacy setting chosen by the operator.
