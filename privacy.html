Privacy policy

Last updated: 26 October 2026

Who this applies to

The ToonMotion applications are internal tools used only by their operator to manage the operator's own YouTube channels and the operator's own TikTok, Instagram and Facebook accounts. They are not offered to the public, and no other users sign in to them.

What data is accessed

With the operator's consent through Google OAuth, the applications use the YouTube Data API and the YouTube Analytics API to:

  • upload the operator's videos and update the operator's channel branding;
  • read the operator's channel and video statistics (views, subscribers, watch time, retention, traffic sources).

With the operator's consent through TikTok Login Kit and Facebook Login, the applications also use the TikTok Content Posting API and the Meta Graph API to publish the operator's videos to the operator's own TikTok profile, Instagram account and Facebook Page, and to read the publishing status of those posts.

No data about other users, viewers or commenters on any of these platforms is collected.

How data is stored and used

OAuth tokens and statistics are stored on the operator's own computers and servers and are used only to run the uploads and the operator's private statistics dashboard. The data is not sold, shared with third parties, or used for advertising. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions (Google), in TikTok under Settings > Security > Manage app permissions, and in Facebook under Settings > Business integrations, after which stored tokens stop working and are deleted.
